What ERAS Does

Built for crisis — designed for clarity

Every feature is purpose-built for emergency resource coordinators.

🧮

Constraint Optimization

Models resource dispatch as a mathematical optimization problem — maximizing total humanitarian impact under a fixed resource budget.

⚡

Greedy Heuristic

Sorts regions by impact-to-resource ratio and allocates top-down. Near-optimal in milliseconds — ideal when speed matters most.

🔬

Knapsack DP — Optimal

Dynamic programming guarantees the mathematically optimal allocation. No combination is left unchecked.

📊

Side-by-Side Comparison

See impact delta, selected zones, resource utilization bars, and a live Chart.js visualization — updated after every run.

🕐

Allocation History

Every run is persisted to SQLite. Browse, filter, expand, and export your full allocation log as CSV.

📈

Analytics Dashboard

Win rates, average impact, improvement trends — visualized with Chart.js line, donut, and bar charts.

🗺️

Preset Scenarios

Load real-scale earthquake, flood, or wildfire scenarios instantly. Data pre-populates the dashboard in one click.

✏️

Edit Regions

Add, edit, or delete any region at any time. A modal editor lets you update any parameter without losing other data.

💾

Persistent SQLite Backend

Express + SQLite backend with a proper REST API at /api/*. Data survives restarts. Regions and history always intact.

Workflow

How It Works

Three steps from crisis to optimal allocation.

1

Configure Regions

Enter each affected zone: name, population, severity (1–10), and resources required. Or load a preset scenario.

2

Set Budget

Enter your total available resource units — the constraint the algorithms must stay within.

3

Run & Compare

Both algorithms run instantly. Compare their selections, impact scores, and resource efficiency side by side.
