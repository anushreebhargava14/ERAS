Algorithm Reference

⚡ Greedy Algorithm

Ranks regions by impact ÷ resource ratio. Allocates greedily from highest-efficiency region down. O(n log n) — fast and usually near-optimal.

🔬 0/1 Knapsack DP

Builds a dp[n][capacity] table evaluating every subset. Guarantees optimal allocation. O(n × W) time.
